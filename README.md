# Ionicons

![](https://img.shields.io/pub/v/ionicons)
![](https://img.shields.io/github/license/ez-connect/flutter-ionicons)
![](https://img.shields.io/github/issues/ez-connect/flutter-ionicons)

This package includes 1357 icons of [Ionicons](https://ionicons.com/) [v8.1.0](https://github.com/ionic-team/ionicons/releases/tag/v8.1.0). The naming convention is derived from the CSS names: kebab-case names are converted to lowerCamelCase, e.g. `add-circle` becomes `addCircle`.

## Usage

There're outline, filled, sharp [icons](https://ionicons.com/).

```dart
import 'package:ionicons/ionicons.dart';

...

Icon(Ionicons.add)
Icon(Ionicons.addOutline)
Icon(Ionicons.addSharp)
```
